## About

Tsala Yame is a multi-device WhatsApp bot built for automation, group moderation, and customization. It is designed to handle common tasks inside WhatsApp chats and groups.

## Features

- Multi-device support
- Auto-reply system
- Anti-link and basic moderation
- Custom commands
- Media and file handling
- Chat interaction tools
